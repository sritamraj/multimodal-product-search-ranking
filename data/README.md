# Data

This directory intentionally contains no downloaded third-party dataset.

Create:

- `catalog.csv`: `product_id,title,description,image_path`
- `qrels.csv`: `query_id,query,product_id,relevance`
- `images/`: product images

For interview-quality results, use a real dataset and document:

1. source URL/name
2. license/usage rights
3. number of products
4. number of queries
5. train/validation/test split
6. relevance-label definition

Do not fabricate relevance labels or benchmark numbers.
